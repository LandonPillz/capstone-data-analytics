# Socioeconomic & Housing Predictors of Burglary Rates in Arizona Cities

## Overview
This capstone project analyzes how socioeconomic and housing factors influence burglary rates across cities in Arizona. The goal is to identify key predictors and evaluate whether burglary rates can be modeled using statistical and machine learning techniques.

The project includes data cleaning, exploratory analysis, predictive modeling, and an interactive Power BI dashboard to communicate insights.

---

## Objectives
- Analyze relationships between socioeconomic factors and burglary rates  
- Test hypotheses based on social disorganization theory  
- Build predictive models (Linear Regression & Random Forest)  
- Create an interactive dashboard for data storytelling  

---

## Technologies Used
- Python (pandas, numpy, scikit-learn, matplotlib)
- Microsoft Power BI
- CSV datasets (PolicyMap)

---


## Data Description
The dataset includes Arizona city-level data with the following variables:

- **Burglary Rate (per 100,000 residents)** — Target variable  
- **Poverty Rate (%)**  
- **Unemployment Rate (%)**  
- **Vacancy Rate (%)**  
- **Single-Parent Households (%)**  
- **Youth Enrollment Rate (%)**  
- **Population (2020 Census)**  

---

## Modeling Approach
Two predictive models were implemented:

- **Linear Regression:** Showed low explanatory power, indicating weak linear relationships between variables  
- **Random Forest Regressor:** Improved predictive performance by capturing non-linear patterns in the data  

---

##  Limitations
- Cross-sectional dataset (no time-based trends)  
- Small sample size after filtering  

---

## Future Improvements
